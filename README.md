# KSIC Mysore Silk

Premium heritage landing page for Karnataka Silk Industries Corporation.

## Open locally

```bash
npx serve .
```

Or open `index.html` directly.

## Stack

Static HTML / CSS / JS. No framework. Design system uses ivory, maroon, and antique gold.

## Key assets

- `assets/hero-saree.png` — primary hero background (supplied ivory silk editorial)
- `assets/ksic-seal.svg` — KSIC seal
- `assets/ganda-berunda.jpg` — Ganda Berunda emblem
